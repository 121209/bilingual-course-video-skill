# 压制与质检

## 压制参数

在用户确认字号样例之后，再压制完整成片。参考命令：

```bash
ffmpeg -y -i "$SRC" \
  -vf "ass=${ASS}:fontsdir=/usr/share/fonts/opentype/noto" \
  -c:v libx264 -profile:v high -pix_fmt yuv420p -preset fast -crf 19 \
  -c:a copy \
  -r 30000/1001 \
  -metadata title="COURSE Lecture N - <原标题>" \
  -movflags +faststart \
  "$OUT"
```

- 老师出镜和底部有空白的幻灯只用 `ass` 滤镜，把字幕烧进完整 16:9 画面。禁止对整讲使用 `pad=1920:1280:0:0:black`，不要把整片画布做成 1920×1280，也不要给这些画面垫黑边。
- 满幅幻灯不要把字幕叠在已经铺满的页面上。把字幕放到该页下方，只在这些帧留底边，使整页可见。这不是整讲垫边，也不要把老师出镜一起垫上。
- 视频：libx264 High、yuv420p、CRF 19、preset fast。
- 音频：`copy` 原英文音轨，禁止重编码、配音、静音或裁短。学生提问、课堂讨论和老师的回答与片源等长，原声和画面都保留。不得因为官方字幕遗漏、听众麦轻或没有字幕而静音、跳切。
- 听不清的段落仍保留原声和画面。字幕用 `[INAUDIBLE]`，或只写听得清的词；不得臆补整句，也不得删掉这段。
- 帧率：若片源是 30000/1001，跟随之；其他帧率不要无故改掉。
- 分辨率：默认与片源一致，1920×1080，完整 16:9。老师出镜和底部有空白的幻灯不缩放、不裁切，四边不加黑边。
- 已有成片不要直接覆盖，先备份。

字体目录按本机 Noto Sans CJK 的实际路径调整。若本机没有该字体，先安装或改用等价的 Noto Sans CJK SC，不要换成会明显改变中文宽度的字体。

## 质检清单

1. 对照课件完成翻译与术语对齐。
2. 按已确认字号生成 ASS（`PlayResX=1920`，`PlayResY=1080`），检查无 5 行 cue，并列出所有英文小于约定字号的条目及实际字号。
3. 先做短样例，送给用户确认。必须包含：一帧满幅幻灯，字幕在页面下方、不盖住该页；一帧老师出镜，字幕在 16:9 画面内底部。并建议覆盖底部有空白的幻灯 2 行 / 4 行、出镜 2 行 / 3 行 / 4 行；如有代码或 Keynote 也要有一帧。老师出镜和有空白的幻灯必须是完整 16:9、默认 1920×1080、无黑边。
4. 用户确认后再压制完整成片。
5. 成片质检：
   - 时长与片源一致（允许与来源标称差 1 秒内），用时长差核对没有跳切；
   - 抽查提问、课堂讨论和老师的回答：原声、画面和时长都在；没有因为官方字幕遗漏、听众麦轻、没有字幕或听不清而被静音或删段；听不清处为 `[INAUDIBLE]` 或只含听得清的词，没有臆补；
   - `silencedetect`（−40 dB，最短 2.5 s）不应出现讲中异常静音（片头片尾静音除外），包括问答段落；
   - 抽帧：老师出镜和底部有空白的幻灯为 16:9 / 1920×1080，字幕在画面内底部，整讲没有一圈或一条永久黑边，滤镜没有对整讲使用 `pad=1920:1280`；满幅幻灯的字幕在页面下方、不盖住该页，只在这些帧可以有底边；两种都不得挡住正文、代码、图示、页脚、页码和脸；
   - 有官方 CC 的段落，音画与 CC 起止对齐；CC 没覆盖的提问、讨论和回答仍保留在成片里。
6. 同时交付：`bilingual.ass`、中英 / 双语 SRT 与 JSON、`qc-report.md`、投稿文案 `posting.md`。
