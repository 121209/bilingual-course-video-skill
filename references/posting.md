# 投稿文案

本 Skill 负责起草投稿文案，不自动把视频发到任何平台。发布需用户另行确认。

## 标题

课程讲次可采用：

```text
【课程编号 · 第X讲】<中文主题>（双语）
```

例如：`【CS329Z · 第四讲】智能体如何使用工具：函数调用与 MCP（双语）`。其他系列沿用该系列已有标题习惯，仍标明讲次和「双语」。

## 简介结构

固定按下面几块写，不要写成一段随笔：

1. 开头钩子：用一两句说明这讲解决什么问题。
2. 「本期主要内容」分条列出要点。
3. 适用对象。
4. 格式说明：保留英文原声；中文在上、英文在下；分辨率与帧率（默认写 1920×1280 及实际帧率）；并可简述字号规则。
5. 原课程 / 原标题 / 主讲 / 原视频 / 课件 / 课程主页；若有官方代码仓库，再加代码链接。
6. 结尾说明，例如：「本视频为原课程的双语字幕翻译整理版。字幕基于课堂录音整理，如有疏漏欢迎指出。」若原课程使用的工具版本可能偏旧，提醒观众按当前环境自行调整。

## 课件评论

只有在用户明确要求把讲义或课件发到评论区时，才起草或发出评论。推荐句式：

```text
第X讲官方课件PDF：https://.../lectureXX.pdf
```

不要在用户未要求时附带 notebook 或其他材料。若某平台稿件仍在审核中，先不要发评论，等用户确认已经过审后再处理。
