# 可复制提示

## 开始一讲（含字号交互）

```text
使用 $bilingual-course-video 翻译这一讲。
请先阅读 SKILL.md，再按「字号交互确认」向我展示推荐的字幕字号方案并说明理由，询问我是否采用。
在我确认字号之前，不要开始翻译。
课程和讲次是：
```

## 只做字号确认

```text
先不要翻译。请按 bilingual-course-video 的字号交互流程，给我一份字幕字号参考建议，并问我采用哪一套。
```

## 已确认字号，继续翻译

```text
字号我确认了，就按 typography.md 里的方案执行。
请先核对官方片源并下载，再翻译、做字号样例给我看。样例通过后再压完整成片。
```

## 通用起步

进入任务文件夹后可以先发：

```text
请先阅读当前文件夹、AGENTS.md 和 typography.md（如果已有），告诉我你理解到的任务目标、已确认的字号、已有材料和缺口，以及下一步。先不要直接翻译或压制完整成片。
```

## 只出样例

```text
请按已确认的字号做短样例，覆盖幻灯 2 行 / 4 行，出镜 2 行 / 3 行 / 4 行。先不要压完整成片。
```
